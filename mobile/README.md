# Namastey Mobile

Expo client for the Namastey API. For local setup and Vercel/EAS deployment instructions, see the [repository README](../README.md).

Set `EXPO_PUBLIC_API_URL` to the API base URL ending in `/api/v1`. Local development can use `mobile/.env` copied from `.env.example`; for a physical device, use your computer's LAN address instead of `localhost`.
